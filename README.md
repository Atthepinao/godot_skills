

# godot_skills

some ai skills using for godot game development

put all skills to YOUR GODOT PROJECT/.agent/skills

## Available Skills
- `design_ui_loop`: Godot UI Designer & Iterator
- `format_gdscript`: Auto-format GDScript code
- `lint_gdscript`: Check GDScript syntax and style
- `list_project_structure`: List project files and folders
- `run_unit_tests`: Run unit tests in Godot Headless mode
- `search_godot_docs`: Fetch official Godot 4.4 documentation
